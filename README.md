# Happy Birthday, My Love ♡

Website chúc mừng sinh nhật với tông hồng pastel và xanh nhẹ, tối ưu cho điện thoại.

## Tính năng

- Bánh sinh nhật, nến lung linh và pháo hoa.
- Chạm vào bánh để thổi nến và tung confetti.
- Ba ảnh chân dung trong khung Polaroid pastel; chạm để mở ảnh lớn, nhấn Escape hoặc nút × để đóng.
- Thiệp thư tương tác và bài có giọng hát “It's Your Birthday!” — Monk Turner + Fascinoma, phát trực tiếp bằng file MP3, không quảng cáo. Điều khiển bằng nút ♫ hoặc thanh phát nhạc.
- Hỗ trợ chế độ giảm chuyển động.

## Sử dụng

Mở `index.html` bằng trình duyệt. Sửa nội dung trong `love-letter` để cá nhân hóa lời chúc.

## Cấu trúc code

- `index.html`: nội dung và bố cục trang.
- `styles.css`: màu sắc, bố cục điện thoại và animation.
- `script.js`: mở thư, thổi nến, pháo hoa và điều khiển nhạc.
- `assets/`: file nhạc và ảnh.
- `img/`: ba ảnh chân dung gốc, dùng trực tiếp trong gallery.

Chạy `npm install`, sau đó `npm run format` để định dạng code hoặc `npm run check` để kiểm tra định dạng và cú pháp JavaScript. Website không cần build.

Website dùng HTML, CSS và JavaScript thuần, có thể triển khai trực tiếp bằng GitHub Pages từ nhánh `main`, thư mục `/ (root)`.

Font Google cần kết nối Internet; trang vẫn dùng font dự phòng khi ngoại tuyến. File nhạc được lưu trong `assets/birthday.mp3`. Nhạc tự phát tùy quyền trình duyệt; khi bị chặn, nhấn ♫ hoặc chạm vào trang.
